PAC-MAN
=======

Eat pellets, dodge ghosts, and clear 10 procedural levels.

Play: https://kapustazh.itch.io/pac-man


INSTALLATION (LINUX)
--------------------
1. Download pac-man-linux.zip
2. Extract the archive
3. Open a terminal in the pac-man folder
4. Run once:  chmod +x pac-man
5. Start:     ./pac-man


CONTROLS
--------
Move              WASD / Arrow keys
Pause             Esc
Confirm           Enter / Space
Fullscreen        F11
Back / menus      Esc

Cheats (during play):
  I   Invincibilityimage.png
  F   Freeze ghosts
  + - Speed up / slow down
  N   Skip level
  L   Add life


OPTIONS
-------
Main menu:
  Start Game, High Scores, Instructions, Exit
  Navigate with Up/Down or W/S, confirm with Enter/Space

Pause menu (Esc):
  Resume, or return to Main Menu (M)


CONFIGURATION
-------------
No config file is required. The packaged game uses built-in defaults.
